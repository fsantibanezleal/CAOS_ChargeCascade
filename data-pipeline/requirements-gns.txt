# ChargeCascade Unit 9 (Rung A): the baked GNS charge-motion surrogate. Offline training + rollout baking only.
# The GNS (Sanchez-Gonzalez et al. 2020, arXiv:2002.09405) is implemented with a self-contained radius graph +
# scatter aggregation, so torch-geometric is NOT required (and its immature ONNX export is avoided; the GNS is
# baked and replayed, never run live). Install into .venv-precompute.
#
#   python -m pip install -r requirements-gns.txt
#   python -m cclab.gns.gen_dem_corpus      # build the corpus from the baked DEM frames
#   python -m cclab.gns.train_gns           # train (RTX 4070 if a CUDA torch is installed, else CPU)
#   python -m cclab.gns.bake_rollouts       # bake the rollouts into demframes/v1 (Mill3D mode 'gns')
